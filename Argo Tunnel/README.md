## 📦 翼龙面板 Node.js 环境部署指南 (内存 ≥ 128MB)

### ✨ 核心特性
* **自动环境清理**：启动时自动检测并清理残留进程与临时缓存。
* **随机安全 UUID**：自动生成标准化 UUID，无需手动配置。
* **标准节点协议**：输出标准的 `VLESS + WS + TLS` 节点链接。
* **灵活优选支持**：支持自行替换与测试不同的 Cloudflare 优选域名与优选 IP。

---

### 1. 临时隧道部署流程

1. 将 `start.sh`、`index.js` 和 `package.json` 上传至面板服务器根目录（无需修改文件内容）。
2. 直接点击开机/启动服务。

> [!NOTE]
> **临时隧道协议说明**  
> 临时隧道默认强制采用 `quic` 协议与单连接模式（此为 Cloudflare 官方默认策略，代码层面无法更改）。

---

### 2. 固定隧道部署流程

1. 将 `start.sh`、`index.js` 和 `package.json` 上传至面板服务器根目录。
2. 在环境变量或配置中填入你的 **固定隧道域名 (`ARGO_DOMAIN`)** 与 **Token (`ARGO_AUTH`)**。
3. （可选）根据网络需求，调整隧道协议 (`ARGO_PROTOCOL`：`http2` 或 `quic`) 及并发连接数 (`ARGO_CONNECTIONS`：`1` - `4`)。
4. 点击开机/启动服务。

> [!WARNING]
> **128MB 极限内存环境建议**  
> 在 128MB 内存环境下，若采用 `quic` 协议，建议将并发连接数设为 `1`（`ARGO_CONNECTIONS=1`），以防止高并发时引发内存溢出 (OOM) 崩溃。
