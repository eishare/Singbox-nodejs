# 🚀 Argo Tunnel & 直连 sing-box部署方案

![简介与说明](https://img.shields.io/badge/%E7%AE%80%E4%BB%8B%E4%B8%8E%E8%AF%B4%E6%98%8E-Argo%E5%86%85%E7%BD%91%E7%A9%BF%E9%80%8F%E3%80%81%E7%9B%B4%E8%BF%9EUDP%2BTCP%E9%83%A8%E7%BD%B2%E6%96%B9%E6%A1%88-red?style=flat-square)

提供高效、稳定且极致轻量化的代理节点部署方案。底层架构采用 **Sing-box + Cloudflared**，配合专门优化的内存守护启动器，确保在低配置 VPS 及极小内存容器中稳定运行。

---

## 💡 特性与适用场景

### 1. 🌐 Argo Tunnel 方案 (内网穿透与穿墙)

专为低配容器及复杂网络环境打造，支持无公网 IP 或被墙服务器的流量中转。

* **TCP / UDP 双模隧道**：灵活应对各类网络环境。
* **精简 Sing-box 架构**：极低资源占用，高吞吐转发。
* **高稳定 Guardian 启动器**：内置 `start.sh` 内存与进程守护机制，精准控制垃圾回收（GC），在低至 64MB 的极限内存环境下依旧稳定不崩溃。
* **📌 适用场景**：
  * 直连线路质量差、UDP 遭受严重 QoS 限速或阻断。
  * 平台未开放入站端口映射或无固定公网 IP。
 ![64MB 专属](https://img.shields.io/badge/内存提醒-64MB%20RAM%20专属-yellow?style=flat-square)

---

### 2. ⚡ 直连高协议方案 (Hysteria2 / TUIC / REALITY)

专为高原生性能与多协议并发打造，支持单端口/多端口的按需部署。

* **灵活组合部署**：
* 
  * **面板仅开放单端口**：支持部署 UDP + TCP 组合节点。
    
  * **面板开放了多端口（≥ 2个）**：支持一键同时部署 Hysteria2 + TUIC v5 + VLESS-REALITY。
    
* **📌 适用场景**：
  
  * 本地直连 UDP 环境良好、无运营商阻断。
  * 平台已开放外部映射端口，追求极致延迟与高码率体验。
